Exploratory Data Analysis

Univariate Exploratory Analysis

Average Rating

We are interested in looking at a films’ average rating as an outcome variable. We will take a look at its distribution using a histogram.

movie_df |> 
  plot_ly(x = ~average_rating,
          type = "histogram", colors = "viridis"
  ) |> 
  layout(
    title = "Distribution of Movies' Average Rating",
    xaxis = list(title = "Average Rating"),
    yaxis = list(title = "Count")
  )

The histogram representing movie average ratings follows a normal distribution, centered at around 3.25.

Runtime

We will explore predictors possibly associated with average ratings, starting with film run time. The distribution of films’ runtime is shown using a histogram below.

movie_df |> 
  plot_ly(x = ~runtime,
          type = "histogram", colors = "viridis"
  ) |> 
  layout(
    title = "Distribution of Movie Runtimes",
    xaxis = list(title = "Runtime (minutes)"),
    yaxis = list(title = "Count")
  )

The histogram representing movie runtimes follows a relatively normal distribution, with a slight right skew, centered at around 125 minutes.

Genre

genre_df = 
  movie_df |>
  mutate(genres = str_remove_all(genres, "\\[|\\]|'")) |>
  separate_rows(genres, sep = ",\\s*")
# Clean genre 
genre_clean_df = 
  genre_df |> 
  group_by(genres) |> 
  summarize(
    n = n()

  arrange(desc(n)) |> 
  filter(n > 16)
genre_clean_df |> 
  mutate(
    genres = fct_reorder(genres, -n)

  plot_ly(x = ~genres, y = ~n,

  ) |> 
  layout(
    title = "Distribution of Movie Genres",

Watches, Fans, Likes, and List Appearance

We are also interested in exploring a film’s number of watches, fans, likes, and list appearances and use them as potential predictors of average rating.

  layout(

  movie_df |>

  movie_df |> 
    plot_ly(x = ~list_appearances,
          type = "histogram", colors = "viridis"

The histograms show that number of watches, fans, likes, and list appearances all a follow heavily right skewed distribution, with most movies centered near the lower end of the scale. Due to the skewdness of these variables, it may be relevant to transform or categorize these variables before conducting further analyses.

Top Films

#create function for top film

top_film = function(df, variable) {
  
  table = 
    df |>
    arrange(desc({{variable}})) |>
    select(film_title, director, {{variable}}) |>
    slice_head(n = 5) |> 
    knitr::kable()

  table
  
}
